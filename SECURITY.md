# Security and live-use safety

This project controls a live Ableton set. Treat every configuration change as
production-critical.

- Test with the PA, interface and monitors muted or disconnected.
- Keep a known-good Companion export and Ableton set backup.
- Confirm that PREV/NEXT only select scenes before using the setup live.
- Confirm STOP and PANIC before every event.
- Do not publish Companion database backups, device serial numbers, credentials
  or local media paths.

To report a security or safety issue, open a GitHub issue without including
private paths, credentials or proprietary media.
